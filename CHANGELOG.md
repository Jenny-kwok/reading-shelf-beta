# Changelog

## 0.4.0
- Reader Feedback is text-first: open Feedback, type immediately, Save.
- Feedback type and area are optional metadata.
- Add Book no longer asks for status; every new acquisition lands in The Shelf.
- The Shelf is not a forced Shelf → Up Next → Currently Reading pipeline.
- A Shelf book can go directly to Start Reading / Currently Reading, or optionally to Up Next.
- Starting a book still creates Day 1 automatically; subsequent starts resume/add sessions.
- Retains retrospective first-start editing, editable/inherited acquisition metadata, single active timer, Journey, Ideas, and scoped exports.
- Export scopes: Everything / Reading Records / Reader Feedback.
